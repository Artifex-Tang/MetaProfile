4. 算法决策细节

burst(k,t) = max(0, (df−E)/σ) ← z-score 版保留(Kleinberg Viterbi 版列为增强)
novelty(k) = 1 − clamp(seen/total)
diversity(k) = 归一 Shannon 熵 / log|S|
strength(k) = .30·novelty + .25·coherence + .20·diversity + .25·velocity
threshold = μ + k·σ(k 可配,首轮地板 0.40) ← max_signals=500 护栏防首轮海量
TEM: x=对象份额, y=份额增速; 切点 x=全体均值, y=0 → strong/weak/latent/nswb
S 曲线: Logistic vs Gompertz curve_fit,AIC 择优; N<0.2L→emerging … >0.8L→mature/saturated
Haupt 比 = 专利 CAGR / 申请人 CAGR
组合新颖 = 含"历史未见 IPC 对"的专利占比(域级聚合)
DisruptScore = Σ wᵢ·zᵢ (0.30/0.25/0.20/0.15/0.10)
Rotolo 判定 = 五属性中位综合 ≥4.0→是, ≤2.5→否, 其间→待定(×3 次取中位抗抖)
fusion v1 = 0.5·burst + 0.3·patent_growth + 0.2·disrupt (citation/invest/policy 三维留接口)
漏斗实测最有说服力的一幕:统计层把成熟域 H04W/H01F 顶上 DisruptScore 前列(novelty z=12 假阳性),LLM Rotolo 判"否"压掉——统计层保召回,LLM 层保精度,双层各司其职。
