## 三、方法学结论(核心)
- **无引文硬约束** → CD index/引文网络全弃;组合新颖性用 IPC 对历史新对占比(Wang 无引文版)
- **配额纪律** → 统计层全库零 LLM;LLM 只碰漏斗末端(Rotolo rubric/项目分类/IPC 命名)
- 实证亮点:G21K|H05H 2025 全新跨域对;G01N/A61K/B23K/H02J=strong+emerging(DT<2 年);LLM 判 H04W/H01F=否正确压掉统计假阳性

## 四、坑账本(铁律,勿再踩)
1. **TripleWriter 写枚举 VALUE=中文类型**("演进/包含/共现")——验证查中文类型;ASCII NAME 查=0 是假象;bash 命令行传中文必坏,用容器内 python
2. **MERGE 关系需两端节点先存在**——down -v/换库后必先回填 tech 节点(upsert_entity_node 全量 tech_profile)再跑 builder,否则静默 no-op 假报 written
3. **asyncio.run 撞 asyncpg 引擎 loop** → 一律 run_async
4. 同步:宽表全表谓词/ORDER BY update_time 爆远端 BE(28GB FullGC)→ pk 分段;远端 600s 超时 → watermark 续传重试;pymysql 不支持 compress
5. curve_fit 模型函数用 np.exp(math.exp(ndarray) 静默崩);pydantic 嵌套类 schema 坏(拉平);候选百万级 IN 爆 32767(分块)
